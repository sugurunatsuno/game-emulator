# Mactician Release Notes — 1.2.2

- Maximum FPS is selected once on the first launch after this update. Your
  subsequent choice is saved and preserved on future launches.
- Detail and effects now offers High and Maximum FPS. The Performance preset
  has been removed.
- New installations also start with Maximum FPS.

- The Donate button now opens sergeinaumov.dev/mactician/donate, which counts
  visits and redirects to the donation provider.

This release contains only these detail-preset and donation-link changes and release metadata.
Game files, rendering profiles and other launcher behavior are unchanged from 1.2.1.
