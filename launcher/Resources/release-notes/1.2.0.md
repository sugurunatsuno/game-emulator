# Mactician Release Notes — 1.2.0

- Choose Global or Vietnam (VNG) on the launch screen. Both editions keep
  their own game data, sign-in and updates; Vietnam downloads on first use.
- Send feedback and vote on requests from the launcher, or support Mactician
  through the Donate button.
- Collect performance metrics for all users, independently of the optional
  Extended Diagnostics choice. They include Mac configuration, game settings,
  launch outcomes, sampled frame times, memory, thermal state and coarse game
  scenes to help compare updates. Screenshots are processed in memory on the Mac and
  are never saved or uploaded.
- Reapply Riot's session-persistence setting so a saved sign-in survives
  game restarts.
- Honor Stop when it is pressed immediately after Play.
