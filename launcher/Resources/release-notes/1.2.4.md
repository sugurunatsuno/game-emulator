# Mactician Release Notes — 1.2.4

- Add a passive experiment to understand whether game-log events can improve
  performance reports. It records predefined event categories, coarse freshness
  and collection timings alongside the existing screenshot diagnostics.
- Keep unavailable or incomplete game context unknown. The experiment does not
  infer the current round or phase from garbage-collection events.
- Raw game logs, account details and screenshots are never saved or uploaded.

Build 53 for Apple Silicon, macOS 12 or later.
