# Mactician Release Notes — 1.2.1

- A refreshed launcher with dark ribbon artwork, a larger title and a compact
  Play / Settings card.
- Installation, launch, running and error screens share the new visual style.
- A dedicated panel for donations and improvement suggestions.
- Game edition and resolution controls are now available in the existing
  Settings window. Open it from a state card or with ⌘,.
- Improved spacing and scrolling for smaller windows in English and Russian.

This release changes only the launcher interface. Game files, runtime behavior
and performance optimizations are unchanged from 1.2.0.
